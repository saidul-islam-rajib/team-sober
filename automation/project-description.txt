DETAILED DESCRIPTION  (field: "Detailed description" — 189 words, Markdown)
---------------------------------------------------------------------------
This project is a complete blog and portfolio platform, and the deployment pipeline is part of the product itself.

**The application.** NestJS renders every page on the server with no separate frontend framework, using TypeScript template literals to generate HTML. Posts, projects, About content, and settings are stored as JSON written atomically to a mounted Docker volume, so content survives container replacements and deployments.

**The delivery pipeline.** A declarative Jenkins workflow checks out the code, builds a Docker image, runs the test suite inside that image, deploys to AWS EC2, and verifies the new container before marking the release successful. The setup also handles image cleanup and blue/green switching to keep releases reliable in a real cloud environment.

**What it offers.** Markdown posts with drafts, backdating, and future scheduling; a searchable portfolio with tag-based navigation; an About page with a timeline and photo gallery; live search; Open Graph previews; sitemap and structured data; and on-demand image resizing for faster, more polished pages.

It is designed as both a content platform and a practical demonstration of shipping software end to end.
